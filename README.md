# Salt & Spice — Wholesale Demo

A standalone, responsive demo website for an Indian grocery wholesaler supplying independent grocery stores and retailers.

## Included
- Product catalogue with search and category filters
- Rice, dals and pulses, spices, flours and pantry essentials
- Product packaging mockups using the Salt & Spice demo identity
- Interactive wholesale quote list with quantity controls
- Copyable product enquiry and enquiry form
- Responsive desktop and mobile layout

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

The site will be available at:
https://devops-integrated.github.io/salt-and-spice-wholesale-demo/

## Important
This is a demo identity and sample catalogue. Pack sizes are illustrative placeholders. There are no live prices, inventory, payment processing, order submission, or backend integrations. The enquiry form only prepares/copies text locally; it does not transmit or store customer details.
